## learned
1. `getBoundingClientRect`: 요소의 크기와 뷰포트에 상대적인 위치를 알 수 있습니다. 메서드를 통해 게임 존의 넓이와 높이를 구해 아이템의 위치를 게임 존 기준으로 랜덤 배치 할 수 있었습니다.
2. `setInterval`을 통해 타이머 카운트를 낼 수 있고 `clearInterval`로 타이머를 정지 시킬 수 있습니다.
